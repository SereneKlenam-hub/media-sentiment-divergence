# Media Sentiment & Narrative Divergence
## Preliminary Results Summary

### 1. Project Objective
This project explores how different sources frame Ghana's Operation Blackout, also known as Operation Cyber Hunt, particularly the disagreement over Ghanaian leadership and the role of international partners, including the FBI.

### 2. Dataset
The initial dataset contains five prepared source summaries:
- Cyber Security Authority (official statement)
- 3News Ghana
- Citi Newsroom — FBI account
- Citi Newsroom — CSA response
- MyJoyOnline

The dataset is saved in `data/processed/articles_dataset.csv`.

**Limitation:** These are summaries rather than full original texts. Several entries describe the same CSA position, so they should not be treated as five independent perspectives.

### 3. Preliminary Sentiment Results
The keyword-based sentiment script labelled:
- One source as Neutral
- Four sources as Negative
- Zero sources as Positive

These labels are generated by counting selected words. They do not reliably measure an author's overall sentiment or opinion. Words related to crime, arrests, and disputes can occur in neutral factual reporting.

### 4. Preliminary Narrative Framing Results
The keyword-based framing script classified:
- Four sources as Ghana-led framing
- One source as FBI/international framing
- Zero sources as Cooperation or mixed framing

The CSA statement and three news summaries emphasizing its response were classified as Ghana-led. The Citi News summary about FBI Director Kash Patel's public account was classified as FBI/international framing.

These results describe the current script's classifications, not the distribution of viewpoints across Ghanaian or international media generally.

### 5. Visualization
The bar chart is saved at:

`data/processed/narrative_framing_chart.png`

The chart displays the number of source summaries assigned to each framing category.

### 6. Preliminary Interpretation
The initial summaries show a contrast between coverage emphasizing Ghanaian authorities' leadership and an account placing the operation within the FBI's broader international campaign against scam centres.

The available summaries are useful for testing the analysis workflow, but more original source material and a larger, more balanced dataset are needed before drawing strong conclusions about media narratives.

### 7. Next Steps
1. Collect and preserve original articles and the original public statements where available.
2. Record each source's publication date, author, source type, and URL.
3. Refine the framing categories and validate labels manually.
4. Review sentiment results in context instead of relying only on keyword counts.
5. Expand the dataset and document the method and limitations before presenting final conclusions.
